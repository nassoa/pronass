# Design System Master — Safidy V2 (Swiss Authority)

> Direction validée : **A — Swiss Authority**  
> Sources : UI UX Pro Max multi-domaine + curation (Inter / cards SaaS exclus)

## Style
Swiss Modernism 2.0 + Exaggerated Minimalism (type) + Trust & Authority (structure)

## Colors
| Role | Hex | Usage |
|------|-----|-------|
| Background | `#F7F8FA` | Page |
| Surface | `#FFFFFF` | Rare — prefer open layout |
| Ink | `#0A0A0A` | Primary text |
| Muted | `#5C6570` | Secondary text |
| Faint | `#9AA3AD` | Labels, meta |
| Line | `#E2E5EA` | Rules / dividers |
| Accent | `#A16207` | CTA only |
| Accent hover | `#854D0E` | CTA hover |
| Inverse | `#0A0A0A` | Dark bands (contact) |
| Inverse text | `#F7F8FA` | On inverse |

## Typography
- **Display / Body:** Instrument Sans (next/font variable)
- **Mono / labels:** DM Mono
- Hero H1: clamp(2.75rem, 7vw, 5.5rem), weight 700–800, tracking -0.04em, line-height ~0.95
- Section titles: clamp(1.75rem, 3vw, 2.75rem)
- Body: 1.0625rem–1.125rem, line-height 1.65

## Layout
- Max width: 1120px
- Base unit: 8px
- Section padding: 96–128px vertical (spacious)
- 12-col mental grid; generous negative space
- Services / principles / pricing: **lists & rules**, not card grids

## Pattern
1. Hero (brand + mission)
2. Proof (companies / experience signal)
3. Services
4. Method
5. Pricing structure
6. Experience timeline
7. About
8. Contact CTA

## Motion
- Scroll reveal: opacity + y 12px, 350ms, ease out
- Stagger 0.04s max
- prefers-reduced-motion: disable

## Anti-patterns
- Purple / pink AI gradients
- SaaS card grids
- Floating hero chips / badges on photo
- Inter / Roboto / system defaults
- Multi-accent colors
- Emoji icons
